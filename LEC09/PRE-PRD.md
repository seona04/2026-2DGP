# PRE-PRD: Sonic Animation Viewer

## 1. 기본 정보
- 개발 언어: Python
- 라이브러리: pico2d
- 파일 이름: sonic_animation_viewer.py
- 구현 방식: 단일 파일로만 작성
- 스프라이트 이미지: sonic-sprite.png

## 2. 프로젝트 목적
스프라이트 시트 이미지를 읽어 각 동작을 자동으로 재생하는 애니메이션 뷰어를 구현한다. 교육용 2D 게임 프로그래밍 과제의 성격상, 이미지의 동작을 시각적으로 확인할 수 있고 반복 재생 구조를 이해할 수 있어야 한다.

## 3. 핵심 기능 요구사항
1. 이미지의 모든 동작을 재생한다.
2. 각 동작은 5회 반복 재생한다.
3. 모든 동작을 다 재생한 뒤 다시 처음으로 돌아가며 무한 반복한다.
4. 화면 대비가 좋고 이미지가 잘 보이도록 충분히 확대한다.
5. 단일 파일로 작성하며, 실행 가능한 형태로 구현한다.

## 4. 구현 방식 요구사항
- 한 번에 전체를 개발하지 않고, 단계별로 구현한다.
- 각 단계마다 커밋을 수행할 수 있어야 한다.
- 최소한 20단계 이상의 개발 단계를 거친다.
- 기능별로 작은 단위의 구현과 검증을 반복한다.

## 5. 개발 단계 계획
1. 프로젝트 범위와 목표를 정리한다.
2. 개발 환경을 점검한다.
3. pico2d 설치 상태를 확인한다.
4. 이미지 파일 위치와 이름을 확인한다.
5. 작업 폴더와 파일 구조를 정리한다.
6. 파일 이름과 실행 방식을 최종 결정한다.
7. 기본 창을 생성한다.
8. 캔버스 크기를 1200 x 800으로 설정한다.
9. 창 배경을 준비한다.
10. 스프라이트 이미지를 로드한다.
11. 이미지 로드 실패를 확인한다.
12. 전체 이미지 크기를 확인한다.
13. 프레임 단위 구조를 분석한다.
14. 중심 좌표와 정렬 기준을 정한다.
15. 한 프레임을 자르는 함수를 작성한다.
16. 프레임 추출 결과를 화면에 출력한다.
17. 동작 목록을 정리한다.
18. 각 동작의 프레임 범위를 정의한다.
19. 동작별 프레임 인덱스를 설계한다.
20. 단일 동작의 재생 로직을 구현한다.
21. 프레임 속도 제어를 추가한다.
22. 한 동작의 재생 속도를 보정한다.
23. 동작별 5회 반복 카운트를 구현한다.
24. 반복 종료 후 다음 동작으로 전환한다.
25. 동작 전환 조건을 검증한다.
26. 전체 루프 재생 로직을 구현한다.
27. 마지막 동작 종료 후 처음으로 이동하는 흐름을 확인한다.
28. 화면 확대 비율을 적용한다.
29. 원본 프레임을 가로세로 4배로 출력하도록 조정한다.
30. 배치와 정렬을 보정한다.
31. 화면 중앙 위치를 맞춘다.
32. 기본 이벤트 처리와 종료 조건을 구현한다.
33. 예외 상황을 점검한다.
34. 프레임 범위 오류를 방지한다.
35. 현재 동작명과 프레임 번호 출력 기능을 추가한다.
36. 디버깅용 로그를 정리한다.
37. 전체 실행 흐름을 점검한다.
38. 루프 유지 상태를 검증한다.
39. 속도와 출력 크기를 재확인한다.
40. 사용자 관점에서 화면 가독성을 검토한다.
41. 코드 정리를 수행한다.
42. 불필요한 중복을 제거한다.
43. 최종 실행 테스트를 수행한다.
44. 오류를 수정하고 안정성을 검증한다.
45. 마지막 커밋 메시지를 정리한다.

## 6. 비기능 요구사항
- 코드가 이해하기 쉬운 구조여야 한다.
- 불필요한 복잡한 추상화는 피한다.
- 애니메이션 재생 과정에서 프레임 인덱스 오류가 발생하지 않도록 한다.
- 프로젝트는 교육 목적에 맞는 단순하고 명확한 구현을 지향한다.
- 추가 파일을 과도하게 만들지 않고, 단일 파일 중심으로 정리한다.

## 7. 완료 기준
- sonic_animation_viewer.py가 정상 실행된다.
- 스프라이트 이미지를 화면에 출력한다.
- 각 동작이 순서대로 재생된다.
- 각 동작은 5회 반복 재생된다.
- 마지막 동작 이후 처음으로 돌아가며 무한 반복된다.
- 이미지가 충분히 확대되어 화면에서 잘 보인다.
- 단계별 개발과 커밋이 가능하다.
- 최소 20단계 이상의 개발 과정을 수행한다.

## 8. 커밋 전략
- 기능 단위로 작은 커밋을 수행한다.
- 각 단계는 확인 가능한 상태로 유지한다.
- 구현이 완료되면 다음 단계로 진행한다.
- 실패한 단계는 빠르게 수정해 다음 단계와 충돌하지 않도록 한다.

## 9. 기대 결과
최종적으로 사용자는 스프라이트 애니메이션이 자동으로 재생되는 뷰어를 실행할 수 있으며, 동작별 반복 재생과 전체 루프 동작이 정상적으로 수행되는 프로그램을 확인할 수 있다.
