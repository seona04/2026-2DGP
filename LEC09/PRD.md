# PRD: Sonic Animation Viewer

## 1. 개요
- 개발 언어: Python
- 라이브러리: pico2d
- 파일 이름: sonic_animation_viewer.py
- 구현 방식: 단일 파일
- 스프라이트 이미지: sonic-sprite.png

## 2. 목표
스프라이트 시트의 동작을 순서대로 재생하고, 각 동작을 5회 반복한 뒤 전체 애니메이션을 무한 반복하는 뷰어를 구현한다. 달리기, 걷기와 같이 이동이 포함된 애니메이션은 프레임 재생과 함께 위치 이동까지 함께 표현할 수 있어야 한다. 이미지는 화면에서 충분히 보이도록 확대하고, 교육용 실습에 적합한 단순한 구조를 유지한다.

구현 기본값은 캔버스 크기를 1200 x 800으로 설정한다. 원본 프레임은 가로와 세로 각각 4배로 출력한다. 따라서 최종 화면에서는 각 프레임이 원본 크기의 4배 확대 상태로 표시된다.

## 3. 요구사항
### 3.1 기능 요구사항
- 프로그램 실행 시 스프라이트 이미지를 로드한다.
- 캔버스 크기는 1200 x 800으로 설정한다.
- 모든 동작을 순서대로 재생한다.
- 달리기, 걷기와 같은 이동 동작은 프레임 재생과 함께 좌우 이동을 함께 처리한다.
- 각 동작은 5회 반복 재생한다.
- 마지막 동작 이후 처음 동작으로 되돌아가며 무한 루프한다.
- 원본 프레임을 가로와 세로 각각 4배로 출력한다.
- 단일 파일로 구현한다.

### 3.2 비기능 요구사항
- 코드는 이해하기 쉽게 작성한다.
- 불필요한 추상화는 피한다.
- 프레임 인덱스와 동작 전환 로직의 오류를 최소화한다.
- 캔버스 1200 x 800 내에서 프레임이 자연스럽게 배치되도록 한다.
- 원본 프레임의 4배 확대 출력이 잘리지 않고 안정적으로 유지되도록 한다.
- 교육 목적에 맞는 단순한 구조를 유지한다.
- 단계별 개발과 커밋이 가능하도록 구성한다.

## 4. 개발 절차
- 전체 기능을 한 번에 구현하지 않고 단계별로 진행한다.
- 각 단계마다 커밋을 수행한다.
- 최소 20단계 이상의 개발 단계를 거친다.
- 기능 단위로 작은 수정과 검증을 반복한다.

36. 디버깅용 로그를 정리한다.
37. 전체 실행 흐름을 점검한다.
38. 루프 유지 상태를 검증한다.

42. 불필요한 중복을 제거한다.
43. 최종 실행 테스트를 수행한다.
